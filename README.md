# 毎日トレーニング

毎日続ける自重トレーニングのための、記録用Webアプリです。

小学生・学生・大学生・大人まで、誰でも使えます。アカウント登録は不要で、スマートフォンでもパソコンでも、ブラウザで開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開きます（インターネット接続は不要です）。
2. 「今日」画面に、その日の種目が表示されます。終わったセットのボタン（「1セット目」など）をタップすると完了として記録されます。
3. すべての種目の目標セットが終わると「今日は完了」と表示され、連続達成日数（ストreak）が伸びていきます。
4. 「履歴」では直近14日の完了・未完了と完了率、累計の完了日数が見られます。
5. 画面上の「マイページ」ボタンで、期間の比較や累計が見られる画面に切り替えられます（URLの末尾に `#mypage` を付けても開けます）。

### マイページ

続けてきた記録を、前の期間と比べられる画面です。

- 期間の比較: 「週」「月」「年」の3つのカードで、完了日数・完了率・完了セット数・合計回数（「回」の種目だけ）を「今の期間 / 前の期間 / 差」で比べられます。完了率はトレーニングの日だけで計算し、休みの日は数に入れません。記録が無い期間は「データなし」と表示されます。
  - 週: 画面上の「週」の選択で対象の週を変えられます（初期状態は今週）。「選んだ週とその前週」の比較で、週は月曜はじまりです。見出しには両方の期間（例: 11月9日〜11月15日 と 11月2日〜11月8日）が出ます。
  - 月・年: 画面上の「年」と「月」の選択で対象を変えられます。月は「選んだ月とその前月」、年は「選んだ年とその前年」の比較になり、見出しにも対象の年月が出ます。年は、記録がある最も古い年から今年まで選べます。選んだ年・月・週は保存されないので、開くたびに今の年・月・週に戻ります。
- 月別グラフ: 選んだ年の12か月分の「完了日数」を横棒グラフで表示します。年を変えるとグラフも切り替わります。
- カレンダー: 選んだ年・月の月カレンダーです。各日に「✓（完了）」「✓短（短縮で完了）」「休（休みの日）」「−（未完了）」の記号が付き、今日の日付は太い枠で示されます。色だけでなく記号でも区別できます。表示専用です。
- 種目別の累計: 全期間を通して、種目ごとの完了セット数と合計回数（「回」の種目だけ）を、完了セット数の多い順に表示します。削除した種目も、その日の記録に残した名前で集計に含まれます。
- 累計: 総完了日数、最長連続日数、現在の連続日数、総完了セット数が見られます。

集計は各日の記録に残した内容（その日の種目名や回数など）をもとに行うため、種目を後から削除・変更しても過去の集計は壊れません。古い記録で回数が分からない分は、合計回数には含めません。

### プロフィール

マイページの先頭に、プロフィール（画像・ニックネーム・紹介文）を付けられます。

- プロフィール画像: 端末から画像ファイルを選ぶと、ブラウザの中で最大256×256に縮小し、容量が大きい場合は圧縮してから保存します。「画像を削除」で外せます。未設定のときは、ニックネームの頭文字が丸い枠の中に表示されます。
- 紹介文: 最大200文字（文字数の表示付き）。「プロフィールを保存」で保存します。
- ニックネームは「設定」にあるものと同じで、プロフィール側から変えても設定側に反映されます。
- 画像と紹介文は、このブラウザの中（localStorage）にだけ保存され、自動で外部に送信されることはありません。端末の外に出るのは、自分で対戦カードを書き出して共有するときだけです。
- JSONエクスポート／インポートの対象には、プロフィール（画像・紹介文）とニックネーム（設定に含まれます）も含まれます。

### 友達と競争（オフライン対戦）

サーバーを介さず、端末同士でJSONファイルを交換するだけで友達と競えます。

1. 「設定」でニックネームを付けておきます（任意。空欄のときは「あなた」と表示されます。本名など個人が分かる情報は入れないでください）。
2. マイページの「友達と競争」で「対戦カードを書き出す」を押すと、自分の対戦カードが入ったJSONファイルが保存されます。「カードをコピー」でクリップボードにコピーして、LINEなどに貼って送ることもできます。
3. 友達からもらった対戦カードを「友達のカードを取り込む」から読み込みます。形式が違うファイルは取り込めません。取り込める友達は最大5人で、同じニックネームのカードを取り込み直すと新しい内容に更新されます。一覧から削除もできます。
4. 自分と友達を並べた比較表が出ます。各指標でいちばんの人には「★」が付き、友達ごとに「○勝○敗（・○分け）」の勝敗サマリーも表示されます。友達の一覧には、その人のプロフィール画像（丸いサムネイル）と紹介文も表示されます。

対戦カードには、ニックネーム・紹介文・プロフィール画像と、サマリーの数字（連続日数、最長連続、今週の完了日数、総完了日数、総完了セット数、合計回数）が含まれ、共有した相手に渡ります。日々の記録そのものは含まれません。カードが端末の外に出るのは、この書き出し・共有のときだけです。紹介文などが入っていない古い形式のカードも取り込めます（その場合は表示が省略されます）。

### 予定の設定

「設定」で、自分の生活に合わせて予定を変えられます。

- トレーニングする曜日: チェックを入れた曜日だけが「トレーニングの日」になります（初期状態は毎日）。外した曜日は「休みの日」です。
- 短縮日にする曜日: 短縮モード（各種目1セット）で始まる曜日を選べます。
- やる時間: 時間帯（朝／昼／夜／決めていない）と、任意の時刻を設定できます。設定すると「今日の予定」に表示されます（例: 「今日はトレーニングの日・夜 21:00ごろ」）。

休みの日については:

- 「今日」画面に「今日は休みの日です」と表示され、完了は必須ではありません。やった分をチェックすれば記録には残ります。
- 連続日数はトレーニングの日だけを数えるので、休みの日が間に入っても連続は途切れません。
- 履歴では「休み」と表示され、完了率や累計の完了日数の対象には入りません。

### 1週間の目標

「設定」で「1週間の目標日数」（月曜〜日曜のうち何日完了したいか）を選べます。初期状態は「設定しない」です。

- 目標を設定すると、「今日」画面に「今週の進捗: 完了○日 / 目標○日」と表示され、達成すると「目標達成！」と出ます。
- 設定しない場合は、「今週の完了○日（今週のトレーニング日は残り○日）」という表示になります。

### ダークモード

画面上の「ダークモードにする」ボタンで、暗い配色に切り替えられます。選んだテーマは設定として保存されます。はじめて開くときは、端末のダークモード設定（prefers-color-scheme）に合わせて表示されます。

### 今日の結果を共有

「今日」画面の「今日の結果を共有」ボタンを押すと、「毎日トレーニング: ○日連続中。今日は○/○セット完了しました。」のような文面を共有できます。端末の共有機能が使える場合はそれが開き、使えない場合は文面がクリップボードにコピーされます。文面に個人情報は含まれません。

### Museのアドバイス

「今日」画面の上に、その日の記録や設定に合わせた短いアドバイスが表示されます。記録をもとに、アプリの中で自動で選ばれるものです。たとえば、休みの日には休むことの大切さ、完了した日にはねぎらい、前回できなかった日には「短縮モードで1セットだけでも」といった提案が出ます。アドバイスのためにデータが外部に送信されることはありません。

### 短縮モード

忙しい日用の機能です。オンにすると、その日の目標が各種目1セットになります。

- 今日だけ切り替えたいとき: 「今日」画面の「短縮モード」トグルを使います。
- 曜日の決まった予定に合わせたいとき: 「設定」の「短縮日にする曜日」で、自分の曜日にチェックを入れます（初期状態では何も選ばれていません）。選んだ曜日は、はじめから短縮モードで始まります。
- 今日画面で手で切り替えた内容が、その日については常に優先されます。

## 種目の増やし方・変え方

種目は固定ではなく、すべて自分で変えられます。

- 追加: 「メニュー」画面の「種目の管理」フォームに名前・数値・単位（回／秒）・セット数・メモ（任意）を入れて「種目を追加」を押します。追加した種目は、その場で今日のリストに反映されます。
- 変更: 一覧の「編集」ボタンから、名前・数値・単位・セット数・メモをまとめて編集できます（保存／キャンセル付き）。
- 並び替え: 「↑ 上へ」「↓ 下へ」ボタンで表示順を変えられます。
- 削除: 「削除」ボタンを押すと確認が出ます。削除直後は「元に戻す」ボタンで取り消せます。種目を消しても、過去の履歴は壊れません（履歴にはその日に記録した内容が残ります）。
- 過去の記録の修正: 「今日」画面の履歴で各日の「編集」を押すと、その日の完了セット数を変更できます。

最初から入っている6種目（腕立て伏せ、クランチ、ヒップリフト、背筋、つま先立ち、プランク）は「はじめのメニュー（テンプレート）」です。自分に合わないものは自由に変更・削除してください。

## データについて

- データは、このブラウザの中（localStorage）にだけ保存されます。取り込んだ友達の対戦カードも同じ場所に保存されます。サーバーなど外部に送信されることは一切ありません。
- 「設定」画面の「データ」セクションから、JSON形式でエクスポート（書き出し）とインポート（読み込み）ができます。機種変更のときなどに使えます。書き出したJSONには形式の版番号（schemaVersion）が含まれます。
- インポート時は、読み込む前にファイル全体の形式を検証します。不正なファイルは読み込まず、現在のデータはそのまま残ります。また、読み込む直前のデータは自動で退避され、「退避したデータに戻す」ボタンで復元できます。「最後に書き出した日」も表示されます。
- 「全データ削除」を押すと、確認のうえですべて消去され、はじめの状態に戻ります。
- ブラウザのデータを消去すると記録も消えるので、大事な記録はときどきエクスポートして保管してください。

## ファイル構成

- `index.html` — 画面の構造
- `css/tokens.css` — 色・余白・角丸などのデザイントークン
- `css/base.css` — リセットと基本要素
- `css/components.css` — コンポーネント
- `css/style.css` — 上記CSSをまとめる入口
- `js/main.js` — すべての処理
- `tests/smoke.test.js` — ロジック検証用の簡易テスト（Node で実行。GitHub Actions でも自動実行されます）
- `manifest.webmanifest` / `images/icon.svg` — ホーム画面に追加したときの名前とアイコン

外部のライブラリやフォントは使っていないため、完全にオフラインで動作します。
